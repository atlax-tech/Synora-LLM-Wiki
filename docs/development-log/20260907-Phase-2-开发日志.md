## 6. 风险预估与规避

- **文件系统/SQLite 无共享事务（极高）**：原件先同卷原子发布，ProductStore 再把 asset metadata 与 placement 文档写入同一个 operation/save 事务；失败路径只清理 staging，恢复按数据库有效资产哈希保留有效原件并删除未提交孤儿。
- **重复导入与并发竞态（高）**：目标以 SHA-256 路径寻址；并发移动遇到已存在目标时视为成功，批量入口串行限制内存，后续只有测得吞吐不足才扩并发。
- **媒体损坏/预览失败（高）**：原件 hash/字节数仍可提交，ImageIO/PDFKit/Quick Look/AVFoundation 失败只返回无缩略图状态，不删除原件；P2-08 再接可操作的媒体视图错误反馈。
- **取消、权限和磁盘故障（高）**：取消、源不可读和目标不可用分别映射错误且 defer 清理 staging；本轮未在受限环境注入权限撤销、磁盘满或进程终止，保留为 P2-12/恢复门的 `UNVERIFIED`。
- **并发改动误提交（高）**：提交前只暂存本轮 Assets/Domain/EditorKit/Store、对应测试和阶段日志；7 个应用/Xcode 文件继续保持未暂存。
